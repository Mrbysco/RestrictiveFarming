# Restrictive Farming #

## About ##
Restrictive Farming allows modpack developers to restrict crops to specific biomes or make them grow slower in non-specified biomes.

By default, the mod makes vanilla crops dimension specific so you can only plant/grow Nether Warts in The Nether.

The mod comes with the following config options:
* **restrictPlacement** - Whether to restrict crop placement to whitelisted biomes
* **reduceGrowth** - Whether to reduce crop growth in non-whitelisted biomes
* **growthGrowthReduction** - The percentage of growth reduction for crops in non-whitelisted biomes (0 = 0%, 0.5 = 50%, 1.0 = 100%)

Crop biomes can be configured through datapacks using the `crop_whitelist` datamap (Tutorial will be made)
